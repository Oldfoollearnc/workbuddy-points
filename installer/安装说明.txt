WorkBuddy 积分观测台 · 安装说明

这是什么
  一个只在本机运行的 Windows 桌面小组件，把 WorkBuddy 的积分余额、
  今日消耗与逐笔流水整理成一块看板。不需要 Python，不上传数据。

系统要求
  Windows 10 1803+ / Windows 11，64 位
  Microsoft Edge WebView2 运行时（Win10/11 通常自带，安装时会检测）

安装
  双击安装包，按向导完成。没有管理员权限时选「仅为我安装」。
  已装旧版可以直接覆盖安装，登录态与历史数据都会保留。

首次使用
  启动后程序常驻托盘。单击托盘图标弹出右下角小窗，
  点小窗右上角「展开完整面板」进入主界面。
  要同步云端余额与流水：主界面右上角头像 → 连接账号，扫码一次。

数据位置
  程序目录：安装时选择的目录
  用户数据：%APPDATA%\WorkBuddyPoints
  升级、重装都不会删除用户数据。

排查
  启动没反应：看 %APPDATA%\WorkBuddyPoints\logs\app.log
  闪退：看同目录下的 crash.log
  Windows 提示「已保护你的电脑」：安装包没有代码签名，
  点「更多信息 → 仍要运行」即可。

移除
  本安装包只负责安装，不提供卸载程序（「应用和功能」里也不会留下条目）。
  要彻底移除：右键托盘图标 → 退出，然后删掉安装目录即可。
  用户数据在 %APPDATA%\WorkBuddyPoints，不在安装目录里；要连登录态一起清掉，
  把那个目录也删掉（重装后就不需要重新扫码了）。
